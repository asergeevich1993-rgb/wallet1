Так как в задании эндпоинт создания кошелька отдельно не описан (только изменение и получение баланса существующего),
реализован отдельный POST /api/v1/wallets для создания кошелька с нулевым балансом 
без этого невозможно было бы получить валидный wallet_id для последующих операций.

Создать кошелек:
POST /api/v1/wallets

Изменить баланс:
POST /api/v1/wallet
{
  "wallet_id": "11111111-1111-1111-1111-111111111111",
  "operationType": "DEPOSIT",
  "amount": 1000
}
Получить баланс:
GET /api/v1/wallets/{WALLET_UUID}

Запуск: 
docker-compose up
